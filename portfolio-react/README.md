# Khadija Iftikhar — Portfolio (React)

## Run it locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
```

Outputs a static site in `dist/` — deployable to Vercel, Netlify, GitHub Pages, etc.

## Structure

- `src/App.jsx` — page layout, assembles all sections
- `src/data.js` — your content (experience, projects, skills) — edit this to update the site
- `src/components/` — Nav, Hero, Experience, Work, Skills, About, Contact, Footer
- `src/index.css` — all styling, including the light/dark theme variables
